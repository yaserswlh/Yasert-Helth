Yaser Fitness — نسخة PWA مجانية
1) ارفع الملفات إلى GitHub Pages أو أي استضافة HTTPS.
2) افتح الرابط من Safari على iPhone.
3) اضغط مشاركة → إضافة إلى الشاشة الرئيسية.
ملاحظة: إشعارات iPhone اليومية حتى لو التطبيق مغلق تحتاج Web Push مع خادم/خدمة إشعارات أو تطبيق iOS أصلي. هذه النسخة مجانية ولا تحتاج API.
